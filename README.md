# Skye Motors

A high-end, industrial-grade luxury and hypercar showcase web application featuring an exclusive multi-brand fleet catalog, interactive 3D/hover car displays, and real-time VIP reservation processing.

## Features

- Split-Hero Cinematic Display: Features a responsive layout paired with an automated, interactive 8-car slideshow.
- 12 Elite Marque Inventories: Comprehensive catalogs spanning Mercedes-Benz/Maybach/Brabus, Porsche, BMW M, McLaren, Toyota GR, Bentley, Audi Sport, Ferrari, Lamborghini, Nissan NISMO, Bugatti, and Rolls-Royce, totaling 72+ unique high-performance models.
- Interactive Technical Modals: Displays detailed pricing, horsepower metrics, specialized active aerodynamics technology, and certified maintenance packages for every vehicle.
- Dynamic Brand Navigation: Clean card-based filtering system with bottom-anchored return navigation for seamless user experience.
- VIP Concierge & Contact Integration: Formspree-powered inquiry processing and quick-access direct communication channels (WhatsApp, Instagram, TikTok, LinkedIn).
- 
## Tech Stack

- Frontend: HTML5, Modern CSS3 (Grid/Flexbox, Custom Floating Keyframe Animations, Ombre Gradients)
- Scripting: Vanilla JavaScript (ES6+ DOM Manipulation, State Management)
- Icons: FontAwesome 6.4.0
- Hosting/Deployment: Vercel
